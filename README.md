# galaxy_renderer
Rendering of a crap ton of stars (stars not included). A bunch of config is available.

Fun fact: If you made a Lego model of the Milky Way with one [stud](https://www.bricklink.com/v2/catalog/catalogitem.page?P=4073&name=Plate,%20Round%201%20x%201&category=%5BPlate,%20Round%5D#T=C&C=12) for each star, it would cost Sam Altman's entire net worth. (For those now wondering about all the stars in the observable universe, the total wealth of the entire Earth would get you 0.0000001% of the way there.)
